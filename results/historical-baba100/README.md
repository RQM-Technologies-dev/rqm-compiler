# Historical benchmark archive

These are the original two-repetition results for compiler commit
`baba100a7715b783671d92066a15804aa08e1e99`, preserved without changing their
reported values. They predate the integrated native-kernel candidate and are
not the current release measurements. The JSON records the original wheel
hash and dependency versions.
